# KeyGati

**KeyGati** is a free online typing speed test designed to help users measure and improve their typing speed, accuracy, and consistency.

## 🌐 Live Website

**[Visit KeyGati](https://prabindangol618.github.io/keygati/)**

## ⌨️ Typing Tests

KeyGati currently provides:

- **Time Test** — Practice typing for 15, 30, 60, or 120 seconds.
- **Words Test** — Complete a set number of words while tracking your performance.
- **WPM measurement** — See your typing speed in words per minute.
- **Accuracy tracking** — See how accurately you type.
- **Character statistics** — Review your typing performance after a test.

## 📚 Typing Guides

KeyGati also provides practical guides covering topics such as:

- What WPM means and how typing speed is measured
- What is considered a good typing speed
- How to improve typing speed
- How to improve typing accuracy
- Touch typing for beginners
- How timed typing tests work
- How words typing tests work

## 🎯 Goal

KeyGati aims to provide a simple, focused, and accessible place for people to test their typing speed and practice regularly without unnecessary distractions.
